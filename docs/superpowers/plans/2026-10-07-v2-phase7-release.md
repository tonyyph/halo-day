# Halo Day v2 · Phase 7 (Release) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Finish v2 for release: the four-step onboarding, the sky-cycling paywall, the widget guide, a new app icon and launch screen, a copy/accessibility pass, removal of every remaining v1 screen and dead component, and a verified release checklist.

**Architecture:** Onboarding and paywall become `SkyScreen`-based v2 views reusing `OrbitCanvas`, `GlassPillStyle` and model actions; the StoreKit purchase logic of v1 (`PurchaseService`, trial eligibility, honest empty-catalog behaviour) is kept verbatim and only re-skinned. The icon is generated by a Swift script from the same sky keyframe colours and Orbit geometry. v1 Theme/Preset code paths with no callers are deleted; the theme palette environment stays only where v2 views still read it.

**Tech Stack:** SwiftUI, StoreKit 2, AppKit (icon script), XCTest/XCUITest.

**Spec:** `docs/superpowers/specs/2026-10-06-halo-day-v2-redesign-design.md` (§4.7, §4.8, §4.5 guide, §9, §10 row 7, §11)

## Global Constraints

As in earlier phases. Paywall: prices, periods and trials come only from StoreKit; with no products the plans show placeholders and purchase is disabled (v1 behaviour). No paywall inside onboarding.

## Review Focus

1. **Onboarding with permissions denied** (calendar, location, notifications) still finishes and lands on Day with labelled sample data.
2. **Onboarding writes** the chosen rituals (replacing the three v1 sample habits only when they are the untouched samples), a starter setup, and `hasCompletedOnboarding` — fixture mode writes nothing.
3. **Paywall with an empty StoreKit catalog**, a pending/cancelled purchase, and restore — no false success, no trial claim without eligibility.
4. **Removing v1 code** leaves no dangling reference (widgets/extension included) and no behaviour the spec still needs.
5. **Accessibility**: VoiceOver can reach every event and ritual on the Orbit (rotors), Dynamic Type AX3 screens keep primary actions reachable, Reduce Motion stops the paywall/onboarding sky animation.
